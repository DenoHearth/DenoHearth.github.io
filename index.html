The addons

Deno Map 4K

Map & minimap · v1.4.1

Every world map and the minimap in four times the resolution.

Button Drawer

Minimap · v1.1.1

One minimap button that holds all the others, with a Lua error button built in.

Deno Dots

Combat · v1.3.0

Your damage-over-time effects and buffs as small icons with timers, and a red mark on what is missing.

Deno Nameplate

Nameplates · v1.2.1

Clean, compact nameplates with health text, cast bars and quest icons.

Raid Recruiter

Groups & raids · v3.3.0

One window for building and running a raid: LFG feed, recruiting, roles, loot rolls.

How they are made

  • For Forever, not ported

    Forever hides combat data from addons. Each addon here is built around what the game allows, with the game's own display tools.

  • Buttons you can see

    The things you do often are visible buttons with a tooltip, not hidden clicks to remember.

  • Standalone

    No libraries to install and no addon depends on another.

  • Open

    All code is on GitHub under the MIT licence, with the scripts that build the textures.
